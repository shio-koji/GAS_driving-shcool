# 箇条書き中心のスライド

ユーザーが好むスライドは、どのページも「短い見出し」と「2階層の箇条書き」で主張を言い切り、画像や図はその主張を裏づける補助として添える形をしている。画像だけ・図だけのページは作らない。

この形を好む理由は、投影中に話し手がいなくても、文字だけで主張が伝わるからだと考えられる。図は直感をくれるが、図だけでは「何が言いたいのか」が読み手に委ねられる。だから主張は必ず文で書き、図はその文を見て「なるほど」と思わせる役に回す。

## 1枚の組み立て

```
見出し（何のページかが分かる短い名詞句か問い）

● 第1階層（抽象）：主張・概念を1行で言い切る
    ○ 第2階層（具体）：例・手順・数値・根拠・引用
    ○ 第2階層（具体）
● 第1階層（抽象）
    ○ …

（必要なら）主張を裏づける画像・図・表
```

### 階層の基本は「抽象 → 具体」

- **第1階層は抽象**：主張・概念・分類・定義。「何が言いたいか」を書く
- **第2階層は具体**：その抽象を裏づける例・手順・数値・固有名詞・引用・根拠
- 読み手は第1階層だけを拾い読みしても要点がつかめ、第2階層で「たとえば？」「本当に？」が解ける。この往復が理解を速くするので、階層の向きを崩さない
- よくある崩れ方と直し方
  - **逆転**：具体が上、抽象が下（「- アプリを開く・保存する／  - どれも裏でプログラムが動く」）→ 入れ替える
  - **具体だけが並ぶ**：第1階層が手順や事例の羅列になっている → それらをまとめる抽象を1行立て、羅列は第2階層に下げる
  - **第2階層が具体ではない**：結果・言い換え・別の主張が下に来ている（「だから〜」「でも〜」）→ 第1階層に上げるか、具体例に置き換える
- 目次・まとめ・手順の一覧のように、項目そのものが要点のページは第1階層だけでよい

### 各要素

- **見出し**：短い名詞句か問いにする（「チームの歴史」「なぜ採択されたのか」）。文を詰め込まない。見出しの読点は外す
- **第1階層**：そのページの主張。1項目1主張で、読めばそれだけで意味が通る文にする。3〜5項目が目安
- **第2階層**：第1階層を支える理由・例・数値・引用。1項目に0〜3つ。第3階層は作らない（深くなるなら別のページに分ける）
- **ラベル付きの列挙**：理由や論点を並べるときは、第1階層を「__理由1 施設の重要性を理解してもらえた__」のように下線つきのラベルにし、中身を第2階層に置く
- **引用**：人の発言や出典の文は第2階層に「」で入れ、出典を添える
- **文末**：箇条は体言止めか言い切りにして、句点（。）は付けない。1項目は投影して1行、長くても2行に収める
- **画像・図・表**：箇条書きの下か横に置く。箇条書きで言った内容を、見て分かる形で補う。図の中にしか書いていない主張を作らない

## 書き換えの手順

既存のスライドをこの形に直すときは、1枚ずつ次の順に進める。

1. そのページで伝えたいことを、図や表も含めて全部書き出す
2. 書き出したものを「主張」と「主張を支えるもの」に分け、主張を第1階層、支えるものを第2階層に置く
3. カード・流れ図・表・大きな一文だけで伝えていた内容は、まず箇条書きにする。図が理解を助けるなら、箇条書きの下に補助として残す。箇条書きと同じことしか言っていない図は消してよい
4. 文言は短く削る。同じ意味なら短いほうを選ぶ。ただし主張・条件・数値・固有名詞は削らない
5. 1枚に収まらないときは、項目を削るのではなく「（1/2）」「（2/2）」に分ける

### 変換の例

**前（図だけで伝えている）**
```
## 伝えるのは「入力」と「出力」
[入力] → [変換] → [出力]
```

**後**
```
## 伝えるのは「入力」と「出力」
- 入力：どこから、何を読むか
- 出力：どこへ、どんな形で出すか
- その間の「変換」はAIが考える
  - カレーなら、材料と完成形を伝えれば作り方はAIが考える
[入力] → [変換] → [出力]   ← 補助の図として残す
```

## 例外として残すもの

- 表紙と章扉（タイトルだけのページ）
- 目次・まとめのページ（番号付きの第1階層だけでよい）
- 用語集のような一覧（箇条書きの一種として扱う）
- 実演の合図など、話し手が画面を切り替えるためだけのページ（それでも1行は言語化する）

## このリポジトリの原稿（slides/slides.md）で書くとき

- 第1階層は `- `、第2階層は行頭に半角スペース2つを付けて `  - ` と書く。番号付きの第1階層（`1. `）の下にも `  - ` を書ける
- 下線つきのラベルは `__ラベル__`、青の強調は `**強調**`、注意は `!!注意!!`
- 図は箇条書きの後に `:::flow` `:::cards` `:::html` などで置く。画像は `![説明](images/ファイル名.png)`
- 左右に分けたいときは `:::cols` を使い、左に箇条書き、右に画像・図を置く
- 書き終えたら `node slides/build.mjs` で生成し、はみ出しがないかブラウザで確認する
- 細かな書き方は slides.md 冒頭の早見表を見る
